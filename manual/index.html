CarCare — Manual Técnico do Desenvolvedor

Documentação arquitetural, operacional e guia prático para desenvolvedores manterem, publicarem e expandirem o ecossistema CarCare.

O CarCare é um produto de software construído com Flutter e Dart, desenhado para gerenciamento preventivo e controle de custos de carros, motocicletas e caminhões. O sistema integra persistência em nuvem em tempo real com o Google Firebase (Authentication e Cloud Firestore), consulta em tempo real à API da Tabela FIPE (para os 3 modais de veículos), radar geolocalizado de serviços automotivos via Google Maps, gestão de documentos (IPVA, Licenciamento Detran e Seguro com guincho 24h), rodízio de pneus, rotina de abastecimento, relatórios analíticos em gráficos de colunas, diário de bordo e alertas municipais de rodízio veicular (incluindo regras de ZMRC para caminhões).

2. Objetivo e Público-Alvo

Objetivo do Software

Eliminar o esquecimento de manutenções preventivas, monitorar o consumo real de combustível por quilômetro rodado (km/l ou km/m³ no GNV), centralizar os custos operacionais do veículo e emitir alertas inteligentes conforme o odômetro avança em relação aos limites de troca de óleo, freios, filtros, transmissão, documentos e pneus.

Público-Alvo

  • Proprietários individuais de carros, motos e caminhões que desejam controle preventivo de custos.
  • Motoristas de aplicativo, caminhoneiros autônomos e entregadores que necessitam de acompanhamento rigoroso de consumo, rotinas de posto e trocas periódicas.
  • Entusiastas e gestores de pequenas frotas que buscam histórico unificado, controle de impostos e valorização do patrimônio.

3. Tecnologias Utilizadas

Flutter & Dart

Framework multiplataforma (Android, iOS, Web, Windows) com arquitetura reativa Material 3.

Firebase Auth

Autenticação segura de usuários por e-mail e senha, com validação de credenciais e recuperação de acesso.

Cloud Firestore

Banco NoSQL em tempo real, modelado com isolamento estrito por usuário (users/{uid}/...).

API Tabela FIPE

Integração REST com a API pública FIPE (Parallelum) para carros, motos e caminhões com cotações atualizadas.

Google Maps & URL Launcher

Busca geolocalizada de postos, mecânicas, borracharias e discagem rápida 24h para guincho/seguradora.

4. Requisitos para Executar o Projeto

  • Flutter SDK: versão 3.19 ou superior (testado com Flutter 3.47 / Dart 3.13).
  • Git: para versionamento e controle de código.
  • Navegador Google Chrome (para execução web rápida) ou Android Studio / VS Code com emulador/aparelho físico.
  • Node.js & Firebase CLI (opcional): npm install -g firebase-tools.

5. Passo a Passo para Instalação

  1. Clone ou abra o repositório no seu computador: 
    git clone <url-do-repositorio>
cd carcare
  2. Instale todas as dependências do Flutter: 
    flutter pub get
  3. Execute o projeto no navegador Chrome: 
    flutter run -d chrome
    (Dica no Windows: use o atalho .\run na raiz do projeto)

6. Configuração do Firebase

O projeto já possui os arquivos pré-configurados pela CLI oficial (firebase_options.dart). Caso precise conectar a outro projeto Firebase:

  1. Acesse o Console do Firebase e crie um projeto (ex: car-care-5c6cf).
  2. Ative o Authentication → Sign-in method → E-mail/senha.
  3. Crie o Firestore Database no modo de produção, na região southamerica-east1 (São Paulo).
  4. Na aba Regras (Rules) do Firestore, publique o conteúdo de firestore.rules.
  5. Execute a CLI oficial do FlutterFire: 
    dart pub global run flutterfire_cli:flutterfire configure

7. Como Rodar e Publicar na Web (Vercel / Firebase Hosting)

Ao compilar o Flutter para web, ele gera arquivos estáticos puros (HTML, JavaScript, WebAssembly e assets) na pasta build/web. Isso significa que o aplicativo pode ser hospedado na Vercel, Firebase Hosting, Netlify ou GitHub Pages e funcionará em qualquer celular ou computador com internet sem precisar instalar nada na loja de aplicativos!

Deploy na Vercel (Passo a Passo)

  1. Gere os arquivos de produção para Web: 
    flutter build web --release
  2. Suba o projeto para o GitHub ou instale a CLI da Vercel: 
    npm install -g vercel
  3. No painel da Vercel (vercel.com):
    • Clique em Add New → Project e importe seu repositório do GitHub.
    • Em Build and Output Settings:
      • Output Directory: defina como build/web
      • Build Command: deixe em branco (se você já fez o build local) ou use um script com o Flutter SDK configurado.
    • Clique em Deploy.
  4. Pronto! Você receberá um link HTTPS gratuito (ex: carcare.vercel.app) que abre perfeitamente em navegadores mobile (Android, iOS Safari, Chrome, Edge) com sincronização em nuvem pelo Firebase.

9. Estrutura do Banco de Dados (Cloud Firestore)

Cada motorista possui sua árvore privada e criptografada em nuvem, garantindo isolamento total:

Coleção Campos Principais Descrição
users/{uid} name, email, createdAt Dados cadastrais do motorista autenticado.
users/{uid}/vehicles/{id} type ('carro'|'moto'|'caminhao'), propulsion ('combustao'|'hibrido'|'eletrico'), brand, model, year, plate, currentKm, transmission, tankCapacity, ipvaDueMonth, ipvaPaid, ipvaAmount, licensingPaid, insuranceCompany, insurancePolicy, insurancePhone, insuranceExpiryDate, lastTireRotationKm, tireRotationIntervalKm, fipeCode, fipeValue, fipeReference, createdAt Carros, motocicletas e caminhões (Combustão, Híbridos e 100% Elétricos) com controle de documentos e pneus.
users/{uid}/maintenances/{id} vehicleId, category, date, km, cost, notes, nextKm, nextDate, createdAt Registros de manutenção com projeção futura de revisão e odômetro anterior visível.
users/{uid}/fuel/{id} vehicleId, fuelType ('Gasolina'|'Etanol'|'Diesel'|'GNV'|'Eletricidade'), date, km, liters, pricePerLiter, totalPrice, isFullTank (bool), gasStation (string), createdAt Abastecimentos e recargas elétricas (kWh) com posto/eletroposto, preço unitário, tanque/carga cheia, calculadora e rotina.

10. Regras de Segurança (firestore.rules)

As regras protegem as subcoleções exigindo autenticação do proprietário:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
      match /{allSubcollections=**} {
        allow read, write: if request.auth != null && request.auth.uid == userId;
      }
    }
  }
}

11. Explicação do Login e Cadastro

  • AuthGate: escuta ativamente o estado de autenticação via stream. Usuários deslogados são direcionados ao Login; usuários autenticados vão direto para a tela principal.
  • Login: valida campos de e-mail e senha com feedback visual em português e suporte à recuperação de senha por e-mail.
  • Cadastro: cria a credencial no Firebase Authentication e grava simultaneamente o documento do motorista em users/{uid}.

12. Tela Principal (Home) e as 5 Abas

O aplicativo organiza toda a experiência em 5 abas integradas:

  1. Início (Visão Geral): cartões de resumo (veículos, gastos no mês, alertas de serviços ativos, consumo médio geral, média diária de distância), radar de serviços automotivos e eletropostos próximos via Google Maps e banner de alerta se hoje for dia de rodízio.
  2. Veículos: listagem de carros, motos e caminhões (Combustão, Híbridos e 100% Elétricos) com odômetro, placa, valor FIPE, chip de rodízio, botão de Lembretes & Documentos (IPVA, Licenciamento, Seguro, Pneus) e acesso ao Diário de Bordo & Termômetro.
  3. Manutenções: histórico de revisões com catálogo inteligente adaptado para Combustão, Híbrido ou 100% Elétrico, odômetro anterior visível, filtro por veículo e botão para Editar ou Excluir.
  4. Abastecimentos / Recargas: histórico com Card de Rotina de Abastecimento / Recarga Elétrica, botão para o Histórico de Postos e Eletropostos, calculadora automática de 3 campos (L, m³ ou kWh), opção de Tanque Cheio / Carga 100% e botão para Editar ou Excluir.
  5. Relatórios: gráficos de colunas interativos por Semana, Mês ou Ano, filtro por Carros, Motos e Caminhões, detalhamento clicável de custos e consumo médio (km/l, km/m³ ou km/kWh) com média diária de km.

13. Gestão de Veículos, Elétricos/Híbridos, Caminhões, FIPE & Rodízio

Suporte Completo a Carros, Motos e Caminhões Elétricos (EV) e Híbridos

O CarCare adapta toda a sua interface e regras de negócio conforme a propulsão do veículo (Combustão, Híbrido ou 100% Elétrico ⚡), com detecção automática ao escolher marcas e modelos conhecidos (BYD, Tesla, Voltz, Watts, GWM, Volvo Electric, VW e-Delivery):

  • 100% Elétrico: oculta combustíveis fósseis (Gasolina, Etanol, Diesel, GNV) e opera exclusivamente com Eletricidade (kWh), calcula eficiência em km/kWh, mede capacidade da bateria em kWh, sugere Eletropostos e exibe apenas itens de manutenção de veículos elétricos (bateria de alta tensão SOH, arrefecimento do inversor/bateria, óleo da transmissão redutora EV, freios regenerativos), sem exibir óleo de motor, velas, correia dentada ou escapamento.
  • Híbrido (HEV / PHEV): permite registrar tanto abastecimentos líquidos (Gasolina/Etanol/Diesel) quanto recargas elétricas (kWh), adiciona itens de revisão do sistema híbrido ao catálogo e calibra o termômetro de consumo para médias híbridas.
  • Isenção Ambiental de Rodízio: veículos Elétricos e Híbridos são automaticamente marcados como Isentos do Rodízio Municipal.

Suporte Completo a Caminhões

O sistema suporta oficialmente Carros, Motos e Caminhões. Para caminhões, o CarCare consulta a Tabela FIPE no endpoint /caminhoes, adota regras de rodízio ZMRC (Zona de Máxima Restrição de Circulação em SP das 05h às 21h em dias úteis) e calibra o termômetro de consumo para médias de diesel pesado (2.0 a 4.5 km/l) ou caminhões elétricos (km/kWh).

Alerta Automático de Rodízio por Placa

O utilitário RodizioHelper lê o último dígito numérico da placa (funciona tanto no padrão tradicional ABC-1234 quanto no Mercosul ABC1D23):

  • Finais 1 e 2: Segunda-feira
  • Finais 3 e 4: Terça-feira
  • Finais 5 e 6: Quarta-feira
  • Finais 7 e 8: Quinta-feira
  • Finais 9 e 0: Sexta-feira
  • Motocicletas e Veículos Elétricos/Híbridos: Isentos de rodízio municipal.
  • Caminhões a Combustão: Sujeitos ao rodízio de caminhões/ZMRC (05h às 21h).

Lembretes de IPVA, Licenciamento, Seguro & Rodízio de Pneus

Acessível em cada veículo pelo botão Lembretes: IPVA, Licenciamento, Seguro & Pneus:

  • IPVA: Mês de vencimento pelo final da placa, valor estimado com base na Tabela FIPE (4% carros, 2% motos, 1.5% caminhões) e botão de marcar como pago/isento.
  • Licenciamento: Calendário oficial do Detran por final de placa com alertas de mês de vencimento.
  • Seguro do Veículo: Nome da seguradora, número de apólice, botão com ligação direta para assistência 24h/guincho e contagem regressiva de renovação.
  • Rodízio de Pneus: Quilometragem do último rodízio, intervalo recomendado (10.000 km), km restantes e barra de progresso visual de desgaste com botão de registro em 1 clique.

14. Manutenções, Alertas Futuros e Odômetro Anterior Visível

No formulário de manutenção, o motorista visualiza em destaque o último odômetro registrado, permitindo copiar o valor com 1 toque ou verificar quantos quilômetros foram rodados desde o serviço anterior.

Ao tocar em qualquer manutenção registrada, o usuário pode clicar no botão "Editar" para retificar custos, data, quilometragem ou observações caso tenha confirmado com algum erro.

15. Abastecimento / Recarga EV, Calculadora Dinâmica, Tanque Cheio & Rotina

  • Calculadora Automática de 3 Campos: Conecta Preço por Litro/m³/kWh, Volume/Carga (Litros, m³ ou kWh) e Valor Total (R$). Ao preencher 2 campos quaisquer, o 3º calcula instantaneamente sem necessidade de contas manuais.
  • Odômetro Anterior em Destaque: Exibe o último odômetro registrado e mostra um badge verde de quantos quilômetros foram rodados neste abastecimento/recarga.
  • Tanque Cheio / Carga 100% vs Parcial: Chave seletora que define se o tanque ou bateria foi completado(a) até 100%. Utiliza o método oficial para calcular o consumo exato daquele ciclo (km/l, km/m³ ou km/kWh).
  • Histórico de Postos e Eletropostos: Registra a bandeira/nome do posto ou eletroposto (Shell, Ipiranga, Tupinambá, Zletric, Wallbox, etc.), histórico de preços pagos e rota no Google Maps com 1 clique.
  • Card de Rotina de Abastecimento / Recarga: Painel estatístico completo exibindo distância média entre paradas, frequência em dias, autonomia estimada com 100% de tanque/bateria, projeção mensal de gastos e a proporção de tanques/cargas completas.
  • Radar de Serviços Próximos (Google Maps): Botão de bússola no topo do app que abre buscas automáticas por postos de combustível, eletropostos EV, mecânicas, borracharias, autoelétricas e guinchos 24h na localização do usuário.

16. Termômetro Visual de Eficiência de Consumo (no Log do Veículo)

O widget TermometroConsumo fica localizado exclusivamente dentro do Diário de Bordo (Log do Veículo) de cada carro, moto ou caminhão, garantindo que cada veículo tenha seu próprio termômetro individual sem misturar médias (e calibrado para Combustão em km/l, GNV em km/m³, Híbridos e Elétricos em km/kWh):

  • Verde (Muito Econômico): Alta autonomia por litro, m³ ou kWh.
  • Amarelo (Normal / Moderado): Consumo padrão esperado para a categoria e motorização.
  • Vermelho (Alto Consumo): Gasto elevado de combustível/energia. Alerta o motorista para checar calibragem dos pneus, alinhamento ou diagnóstico do sistema.

17. Gráficos de Colunas e Relatórios Financeiros

Localizado na aba Relatórios:

  • Gráficos por Período: escolha visualizar gastos por Semana (dias de Seg a Dom), Mês (4 semanas do mês atual) ou Ano (12 meses).
  • Colunas Coloridas: divisão proporcional e empilhada entre gastos de Combustível / Energia (Dourado) e Manutenções (Azul).
  • Interativo (Drill-Down): tocar em qualquer coluna abre o detalhamento exato com a lista de tudo o que foi gasto naquele período específico.
  • Tabela de Consumo: resumo da frota com litros/kWh registrados, consumo em km/l ou km/kWh e avaliação de eficiência.

18. Diário de Bordo (Log Unificado do Veículo)

A tela TelaHistoricoVeiculo consolida a linha do tempo completa do carro, moto ou caminhão, trazendo o Termômetro de Consumo individual do veículo, o card de rotina de abastecimento/recarga e, em ordem cronológica reversa, todas as manutenções executadas, abastecimentos/recargas, evolução do odômetro e gastos acumulados com filtros rápidos (*Tudo*, *Serviços* e *Abastecimentos/Recargas*).

19. Central de Dúvidas Frequentes (FAQ)

Acessível pelo botão flutuante amarelo com interrogação ? no canto inferior esquerdo da tela inicial do CarCare. Traz respostas rápidas organizadas com busca instantânea e filtros por categoria. Abaixo está a base de conhecimento completa:

🚗 Veículos & Rodízio
Como cadastrar meu carro, moto ou caminhão?
Na aba "Veículos" ou no botão flutuante da tela inicial, toque em "Novo Veículo". Selecione se o veículo é um Carro, Moto ou Caminhão, escolha a motorização (Combustão, Híbrido ou 100% Elétrico ⚡) e escolha a Marca e o Modelo diretamente na lista pesquisável. Você também pode tocar em "Consultar Tabela FIPE" no card do veículo para puxar automaticamente o ano oficial e o valor médio de mercado!
Como funciona o suporte para Carros, Motos e Caminhões Elétricos ou Híbridos?
Ao cadastrar ou editar um veículo, você pode selecionar a motorização entre "Combustão", "Híbrido" ou "100% Elétrico ⚡" (além disso, ao escolher marcas/modelos conhecidos como BYD, Tesla, Voltz, Watts, GWM Haval ou VW e-Delivery, o app detecta a propulsão automaticamente!). Quando o veículo é 100% Elétrico, o app adapta tudo: • Recargas exclusivamente em Eletricidade (kWh) e eficiência medida em km/kWh (sem opções de Gasolina, Etanol ou GNV). • Capacidade da bateria em kWh e sugestões de Eletropostos (Tupinambá, Shell Recharge, Zletric, Wallbox). • Catálogo de manutenção exclusivo para veículos elétricos (bateria de alta tensão, arrefecimento do inversor, óleo do redutor EV, freios regenerativos), ocultando itens de motor a combustão (óleo de motor, velas, correia dentada, escapamento). • Isenção ambiental automática no Rodízio Municipal.
Como o app avisa o dia do meu rodízio veicular?
O CarCare lê o último número da placa informada (padrão antigo ou Mercosul) e calcula o dia da restrição de trânsito (ex: finais 1 e 2 na segunda-feira, 3 e 4 na terça, etc.). Se hoje for o dia do rodízio do seu carro, um banner amarelo em destaque surge no topo da tela inicial. Motocicletas e veículos Elétricos/Híbridos são identificados automaticamente como isentos do rodízio municipal.
Como funciona o rodízio para caminhões (ZMRC)?
Para caminhões, o aplicativo adota as regras oficiais da Zona de Máxima Restrição de Circulação (ZMRC). A restrição para caminhões vigora em dias úteis das 05h00 às 21h00 conforme o final da placa. O banner e o card do veículo alertam o motorista sobre esse horário estendido.
Como atualizar o valor do veículo pela Tabela FIPE?
Na aba de Veículos, toque sobre o seu carro, moto ou caminhão e clique em "Consultar" no campo Tabela FIPE. Selecione a Marca, Modelo e Ano. O aplicativo busca diretamente na API oficial da FIPE e atualiza o valor médio de mercado e o código de referência do veículo.
⛽ Combustível, Recarga EV & Consumo
Como funciona o cálculo de quilometragem e consumo?
Ao cadastrar um abastecimento ou recarga elétrica, o app exibe a quilometragem anterior registrada. Ao digitar o novo odômetro e os litros/kWh, o app calcula na hora a distância percorrida e o rendimento do trecho (km/l, km/m³ ou km/kWh). Ao salvar, a quilometragem do veículo no banco é atualizada automaticamente!
Posso abastecer com Etanol, Diesel, GNV ou Eletricidade (kWh)?
Sim! O formulário adapta as opções de acordo com a motorização do veículo: veículos 100% elétricos usam Eletricidade (kWh); veículos híbridos oferecem tanto combustíveis líquidos quanto Eletricidade (kWh); e veículos a combustão oferecem Gasolina, Etanol, Diesel e GNV (m³).
Para que serve marcar a opção "Tanque Completo / Carga 100%"?
Completar o tanque (ou carregar a bateria até 100%) é a forma padrão da engenharia automotiva para saber o consumo exato do veículo. Quando você marca essa opção, o app calcula a média exata de km/l ou km/kWh entre dois ciclos completos. Se foi parcial, deixe a chave desmarcada para acumular até a próxima carga completa.
Como funciona a calculadora automática no abastecimento / recarga?
No formulário, os campos "Preço por Litro/kWh", "Volume/Carga" e "Valor Total Pago" estão interligados em tempo real: • Digite o Preço unitário e os Litros/kWh ➔ O Total Pago é calculado na hora. • Digite o Preço unitário e o Total Pago ➔ A quantidade de Litros/kWh é calculada na hora. • Digite os Litros/kWh e o Total Pago ➔ O Preço unitário é calculado na hora.
O que é o card "Rotina de Abastecimento / Recarga"?
É um painel estatístico inteligente na aba de Abastecimentos e no Log do Veículo que analisa o seu padrão de uso: • Distância entre paradas: quantos km você roda em média antes de abastecer/recarregar. • Frequência: a cada quantos dias você costuma parar no posto/eletroposto. • Autonomia estimada: projeção de quantos km seu tanque cheio ou bateria em 100% rende. • Projeção mensal: estimativa de quanto você gastará no mês. • Barra inferior: percentual de registros feitos com tanque cheio ou carga 100%.
Onde fica e o que significa o Termômetro de Consumo?
Cada veículo possui seu próprio Termômetro de Consumo exclusivo dentro do "Diário de Bordo / Log do Veículo" (basta tocar no veículo e abrir o Diário de Bordo). Ele indica se o consumo médio daquele veículo está eficiente: • Verde (Muito Econômico): Alta autonomia por litro, m³ ou kWh. • Amarelo (Normal / Moderado): Consumo padrão esperado para o combustível/energia e tipo de veículo. • Vermelho (Alto Consumo): Indica consumo elevado. Vale a pena verificar calibragem dos pneus e revisão preventiva.
📍 Serviços, Postos & Eletropostos
Como encontrar postos, eletropostos, mecânicos e borracharias próximos?
No topo do app (na barra superior), toque no ícone de Bússola. O painel "Radar de Serviços Próximos" permite encontrar com 1 toque no Google Maps: Postos de Combustível, Eletropostos / Recarga EV, Oficinas Mecânicas, Borracharias 24h, Autoelétricas, Lava-rápidos e Auto Socorro / Guincho na sua região atual.
O que é o Histórico de Postos Frequentados?
Na aba "Abastecimentos", toque no botão "Histórico de Postos Frequentados". Nele você visualiza todos os postos e eletropostos onde já abasteceu/recarregou, quantidade de visitas, total gasto em reais, volume/energia e os preços históricos por L, m³ ou kWh, além de um botão para abrir rota no Google Maps!
📄 Documentos & Pneus
Como funciona o controle e lembrete de IPVA?
Ao abrir os detalhes do veículo, toque em "Lembretes: IPVA, Licenciamento, Seguro & Pneus". O CarCare calcula o mês de vencimento oficial do IPVA pelo final da placa, estima o valor com base na alíquota do estado sobre a Tabela FIPE (4% carros, 2% motos, 1.5% caminhões) e permite marcar o imposto como Pendente, Pago ou Isento.
Como funciona o lembrete de Licenciamento Anual (Detran)?
O app acompanha o calendário oficial do Detran pelo dígito final da placa (de Julho a Dezembro). Ele avisa se o documento está regular, no mês de vencimento ou em atraso, com botão para confirmar o pagamento anual.
Como cadastrar o Seguro e acionar o Guincho 24h rapidamente?
No modal de Lembretes do veículo, você pode cadastrar a Seguradora, número da Apólice, data de renovação e o telefone de assistência 24h. Quando precisar de um guincho ou socorro, basta tocar no botão de chamada rápida para discar diretamente sem precisar procurar papelada.
Como funciona o controle de Rodízio de Pneus?
O rodízio de pneus prolonga a vida útil dos pneus e melhora a segurança. O CarCare monitora o intervalo padrão de 10.000 km, exibindo uma barra visual de desgaste e a quilometragem restante. Ao fazer o rodízio, basta tocar em "Registrar Rodízio Hoje" para atualizar o odômetro da troca.
🔧 Manutenções & Alertas
Como funciona a visualização do odômetro anterior no cadastro?
Sempre que você for cadastrar uma nova manutenção ou abastecimento, o app mostra em destaque a última quilometragem registrada e calcula em tempo real quantos km você rodou desde a última vez, evitando que você digite quilometragens inferiores por engano.
Como editar ou corrigir uma manutenção ou abastecimento já salvo?
Se você confirmou um abastecimento ou manutenção e percebeu que digitou algo errado, basta tocar sobre o item na lista e clicar no botão "Editar". Altere os valores desejados e salve novamente sem perder o histórico.
O que é o Diário de Bordo (Log do Veículo)?
O Diário de Bordo é a linha do tempo completa do seu veículo. Nele você vê em ordem cronológica reversa todas as manutenções e abastecimentos, total gasto, evolução do odômetro e a média diária de km rodados.
Como funcionam os alertas de revisão preventiva?
Ao registrar uma manutenção (ex: troca de óleo), ative "Agendar próximo serviço" e defina o próximo km ou data. O aplicativo monitora o avanço do odômetro e avisa na tela inicial quando o serviço estiver próximo ou atrasado.
📊 Gastos & Relatórios
Como ver os gráficos de gastos por semana, mês e ano?
Na aba "Relatórios", você encontra gráficos de colunas com filtros por Semana, Mês ou Ano, podendo filtrar entre Carros, Motos e Caminhões. Ao tocar em qualquer coluna, o aplicativo abre o detalhamento exato com tudo o que foi gasto no período!
O que é a Média Diária de Distância (km/dia)?
É um cálculo que divide os quilômetros rodados pela quantidade de dias entre os registros. Essa métrica ajuda a saber o ritmo real de uso do veículo para planejar despesas e próximas trocas de óleo.
☁️ Conta & Nuvem
Meus dados ficam salvos se eu trocar de aparelho?
Sim! Todos os seus dados ficam salvos com segurança na nuvem pelo Google Cloud Firestore. Basta fazer login com o mesmo e-mail e senha em qualquer celular ou computador para acessar seus veículos.

21. Como Trocar o Logo

  1. Gere uma nova imagem quadrada (PNG 1024x1024 px).
  2. Substitua em assets/images/logo.png e manual/imagens/logo.png.
  3. Execute no terminal para recriar os ícones de todas as plataformas: 
    dart run flutter_launcher_icons

22. Como Alterar o Nome do Aplicativo

  1. No Flutter: altere nomeApp em lib/utils/constantes.dart.
  2. No Android: altere android:label em android/app/src/main/AndroidManifest.xml.
  3. Na Web: altere a tag <title> em web/index.html.

23. Como Adicionar ou Alterar uma Tela

Crie o arquivo em lib/screens/tela_minha_nova_tela.dart e navegue utilizando:

Navigator.push(
  context,
  MaterialPageRoute(builder: (context) => const TelaMinhaNovaTela()),
);

24. Como Adicionar ou Alterar um Campo no Banco de Dados

  1. Adicione a propriedade no Model (lib/models/...), construtor, toMap() e fromDoc().
  2. Adicione o campo correspondente no formulário da tela (_FuelFormSheetState, _VehicleFormSheetState, etc. em lib/screens/home/tela_principal.dart).

25. Como Gerar uma Nova Versão do Projeto (Build)

  1. Incremente o número da versão em pubspec.yaml (ex: version: 1.0.1+2).
  2. Para Web: flutter build web --release
  3. Para Android APK: flutter build apk --release
  4. Para Windows Desktop: flutter build windows --release

26. Solução de Problemas Comuns (Troubleshooting)

Bloqueio de pasta no Windows / OneDrive ("Flutter failed to delete a directory at build\flutter_assets")

Ocorre quando um processo anterior do Dart fica preso ou o OneDrive segura a pasta aberta. Basta executar o script .\run na raiz do projeto ou rodar no PowerShell: Stop-Process -Name dart -Force; cmd /c "rmdir /s /q build".

Aviso: "flutterfire não é reconhecido"

Adicione %LOCALAPPDATA%\Pub\Cache\bin à variável PATH do sistema Windows.
